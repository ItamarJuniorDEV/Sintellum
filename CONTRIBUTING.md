# Contribuindo com o Sintellum

1. Crie uma branch a partir da `main`.
2. Escreva o teste antes da implementação para comportamento novo ou correção.
3. Rode `npm run lint`, `npm run typecheck`, `npm run test:unit` e `npm run test:integration`.
4. Não introduza execução de código do workspace analisado.
5. Relações não comprovadas pelo código não podem ser marcadas como `confirmed`.
6. Mudanças que enviem mais código para provedores cloud precisam de revisão explícita de privacidade.

Pull requests devem explicar o comportamento alterado, testes adicionados e impacto de segurança/privacidade.
